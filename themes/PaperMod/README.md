## 特性 💥

`☄️ 快速 | ☁️ 流畅 | 🌙 平滑过渡 | 📱 响应式设计`

- **资源管道** -- 使用 Hugo 内置的资源生成器，支持指纹识别、打包和压缩。
- **三种布局模式** -- [常规模式](https://github.com/adityatelange/hugo-PaperMod/wiki/Features#regular-mode-default-mode), [首页信息模式](https://github.com/adityatelange/hugo-PaperMod/wiki/Features#home-info-mode), 和 [个人主页模式](https://github.com/adityatelange/hugo-PaperMod/wiki/Features#profile-mode)。
- **浅色和深色主题** -- 根据浏览器偏好自动切换，并支持手动切换按钮。
- **多语言支持** -- 内置语言选择器。
- **搜索功能** -- 基于 Fuse.js 的客户端搜索。
- **SEO 优化** -- 开箱即用的 Open Graph, Twitter Cards 和 Schema.org 结构化数据。
- **封面图片** -- 支持每篇文章设置封面图，并具备响应式图片支持。
- **目录 (ToC)** -- 根据标题结构自动生成目录。
- **多作者支持** -- 原生支持多作者站点。
- **社交图标和分享按钮** -- 可配置的社交链接和每篇文章的分享功能。
- **面包屑导航**
- **文章归档和分类法**
- **代码块复制按钮** -- 一键复制代码，配合 Chroma 语法高亮。
- **相关文章推荐**
- **零 JS 构建依赖** -- 不需要 webpack, Node.js 或其他工具链。
